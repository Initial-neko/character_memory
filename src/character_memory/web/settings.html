Secrets

API Key / Token 只保存到 .env；系统环境变量优先级更高。页面不会读取或返回明文 Key。

生效规则

当前 V1 不做部分热更新。保存普通配置会先生成 config.yaml.bak.YYYYMMDD-HHMMSS，再原子替换配置；Secret 写入 .env，不会生成包含 Key 的历史备份。

保存完成后执行一次 Ctrl+C 停止当前 stack，再运行 uv run character-stack。正式聊天 TTS 由这里的 TTS Provider / TTS Voice / Speed / Device 决定；不可用 Provider 会被禁用，保存时服务器会再次执行健康校验。
