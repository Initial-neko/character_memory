生效规则

普通 YAML 配置仍以字段级 patch 方式保存，并保留未知字段、注释和原有顺序；Secret 与 GSV Runtime 资产参数写入项目 .env，不会覆盖其他已有环境变量。

TTS Provider / Voice / Speed / Device 与 GSV Runtime 参数支持热生效：Media Runtime 每次请求读取最新 TTS 选择，GSV 参数变更只重配/重载 :9014 sidecar，不需要重启 Character / Media / Settings 整个 stack。其他非 TTS 字段仍以页面返回的 restart_required 为准。
